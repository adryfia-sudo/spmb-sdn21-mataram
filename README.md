# SPMB Online

Sistem Penerimaan Murid Baru berbasis Laravel.

## Fitur

- Pendaftaran online
- Jalur pendaftaran
- Validasi NIK/NISN
- Upload dokumen
- Verifikasi
- Cek status
- Pengumuman
- Bukti pendaftaran
- Pengaturan persyaratan
- Pengaturan tahun akademik
- Pengaturan kuota
